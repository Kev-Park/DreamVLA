# Attribution and distribution scope

This contribution builds on [DreamControl](https://github.com/GenRobo/DreamControl)
and [Kevin Park's DreamVLA branch](https://github.com/Kev-Park/DreamVLA/tree/g1).
The copied DreamControl reference generators, task definitions and derived robot
configuration retain the upstream repository license. The accompanying `LICENSE`
copies that license's terms, not a claim that all dependencies share it.

Isaac Lab-derived files retain their existing copyright notices and
`BSD-3-Clause` identifiers. Do not remove those notices when modifying or moving
them. The license text is in `LICENSES/IsaacLab-BSD-3-Clause.txt`. Follow the
upstream license for the original shared backend as well.

The package interfaces with NVIDIA
[GR00T Whole-Body Control / SONIC](https://github.com/NVlabs/GR00T-WholeBodyControl)
and [Isaac-GR00T](https://github.com/NVIDIA/Isaac-GR00T). Their source, weights,
datasets and assets remain governed by their own licenses and access terms.
NVIDIA/Omniverse simulator and asset terms are separate from this contribution.
No model weights, external robot meshes, cabinet/panel assets, or third-party
environment installs are redistributed here.

The staged addition is code-only. Historical results already present elsewhere
in the upstream repository are not newly contributed by this directory.
